# ArAmir OS — если что-то случилось: как вернуть данные и проект

Три вещи, которые нужно уметь вернуть. Каждая хранится в своём месте, и у каждой своя копия.

| Что | Где живёт | Где должна лежать копия |
|---|---|---|
| **Код** (сама платформа) | GitHub `Odysseusex/New-OS` | ZIP-архив у владельца (GitHub → Code → Download ZIP), раз в месяц |
| **Данные** (продажи, остатки, бонусы, всё) | база Neon | файл «Скачать все данные» (Настройки → «Резервная копия данных»), раз в неделю |
| **Ключи и пароли** (адрес базы, токены ботов, WhatsApp) | настройки Render | менеджер паролей владельца (не в чате, не в телефоне единственным экземпляром) |

Чего нет ни в одной копии: **паролей сотрудников** — в файл выгрузки они намеренно не попадают. После
восстановления у всех один временный пароль, который печатает скрипт; люди меняют его при первом входе.

## Сценарий 1. Данные испорчены или пропали, а код цел

1. В Neon создать новую пустую базу (или новый проект) и скопировать её адрес подключения.
2. В папке `apps/api` на компьютере с кодом:
   ```bash
   export DATABASE_URL="<адрес новой базы>"
   npx prisma migrate deploy        # создаёт пустую структуру
   npx ts-node scripts/restore-export.ts путь/к/aramir-data-ГГГГ-ММ-ДД.json --yes
   ```
3. Скрипт:
   * откажется работать, если в базе уже есть хоть одна строка (чужие данные не затирает);
   * загрузит всё **одной операцией** — либо всё, либо ничего;
   * сверит число строк в каждой таблице с файлом;
   * напечатает временный пароль для всех пользователей.
4. На Render заменить `DATABASE_URL` на адрес новой базы (Environment → Save → сервис перезапустится).
5. Войти владельцем с временным паролем и сменить пароли (Настройки → сотрудники).

Проверено: выгрузка демо-базы (со включённой главной книгой) → чистая база → таблица за таблицей
совпала до последней цифры, P&L и остатки на восстановленной базе совпали с исходной.

## Сценарий 2. Пропал GitHub (код)

1. Взять последний ZIP с кодом (см. таблицу).
2. Создать новый репозиторий, загрузить код, подключить к нему Vercel и Render (Settings → Git).
3. Новой сессии Claude Code достаточно сказать: «прочитай `CLAUDE.md`, `docs/HANDOFF.md` и `docs/RESTORE.md`»
   — в них записано, как всё устроено и зачем. Сам Claude **не помнит прошлых разговоров**: память проекта
   — это код и эти документы.

## Сценарий 3. Всё пропало (и код, и база)

Код — из ZIP, данные — из файла выгрузки (сценарии 1 и 2). Без хотя бы одной копии кода платформу
придётся писать заново: по памяти её не восстановить. Поэтому ZIP нужен.

## Ключи, которые надо где-то хранить (список названий, сами значения — только в менеджере паролей)

* Адрес базы `DATABASE_URL` (Neon)
* `JWT_SECRET` и прочие ключи в Environment на Render
* `WEB_ORIGIN`, `NEXT_PUBLIC_API_URL` (не секреты, но без них сайт не заработает)
* Токены Telegram-ботов (`TELEGRAM_BOT_TOKEN`, `CUSTOMER_BOT_TOKEN`) — их можно выпустить заново в @BotFather
* WhatsApp: `WHATSAPP_TOKEN`, `WHATSAPP_PHONE_NUMBER_ID`, `WHATSAPP_BUSINESS_ACCOUNT_ID`, `WHATSAPP_APP_SECRET`
* Доступ к кассе re:Kassa (если включена)
* Входы в сами сервисы: почта, GitHub, Vercel (там же домен ar-amir.com), Render, Neon, Meta —
  у каждого сохранить **коды восстановления двухэтапной проверки**

## Что делает «Скачать все данные» (для разработчика)

`GET /api/backup/export`, только роль OWNER, запись в журнал действий (`dataExport.download`).
Весь файл читается в одном снимке базы (`REPEATABLE READ`), поэтому все таблицы — на один и тот же миг,
и отдаётся потоком страницами по 1000 строк. Формат: `apps/api/src/backup/backup-format.ts`.
В файле нет `users.passwordHash`, нет `telegram_link_tokens` и `_prisma_migrations`. Последнее поле файла —
`"complete":true`: оборванное скачивание его не содержит, и скрипт такой файл не принимает.
Циклические ссылки (организация ↔ пользователь) обрабатываются так: необязательная ссылка при загрузке
пропускается и проставляется в конце (`deferred` в файле). Колонку, на которую наложено CHECK-ограничение,
так не откладывают. Новая колонка с «секретным» именем без решения о ней ломает тест `backup.spec.ts`.
